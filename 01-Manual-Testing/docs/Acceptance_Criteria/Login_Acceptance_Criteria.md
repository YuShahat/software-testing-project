# Login Acceptance Criteria

| ID | Acceptance Criteria |
|----|---------------------|
| AC-001 | User can log in with a valid email and password. |
| AC-002 | An error message is displayed for invalid credentials. |
| AC-003 | Password is hidden while typing. |
| AC-004 | User is redirected to the home page after successful login. |
| AC-005 | User session remains active until logout. |
| AC-006 | Required fields are validated before submission. |
