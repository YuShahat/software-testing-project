# Test Plan

## Project Information

**Project Name:** E-Commerce Web Application

**Application Type:** Web Application

**Testing Type:** Manual Testing

**Prepared By:** Youssef Shahat

**Version:** 1.0

---

# 1. Introduction

This document describes the testing strategy, objectives, scope, resources, and schedule for testing the E-Commerce Web Application.

---

# 2. Objectives

The objectives of testing are:

- Verify application functionality.
- Ensure all business requirements are satisfied.
- Detect defects before release.
- Improve software quality.

---

# 3. Scope

### In Scope

- User Registration
- Login
- Logout
- Product Search
- Product Details
- Shopping Cart
- Checkout
- Contact Us

### Out of Scope

- Payment Gateway Integration
- Third-party Email Services

---

# 4. Test Types

- Functional Testing
- Smoke Testing
- Regression Testing
- UI Testing
- Exploratory Testing

---

# 5. Test Environment

Operating System:
Windows 11

Browser:
Google Chrome (Latest)

Internet:
Stable Internet Connection

---

# 6. Entry Criteria

- Requirements are available.
- Application is deployed.
- Test environment is ready.

---

# 7. Exit Criteria

- All critical defects are fixed.
- High-priority test cases are executed.
- Test Summary Report is completed.

---

# 8. Deliverables

- Test Plan
- Test Scenarios
- Test Cases
- Bug Reports
- RTM
- Test Summary Report

---

# 9. Risks

- Requirement changes.
- Environment instability.
- Time limitations.
