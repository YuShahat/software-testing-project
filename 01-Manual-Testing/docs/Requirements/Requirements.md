# Requirements Document

## Project Overview

The system is an E-Commerce web application that allows users to browse products, register, log in, manage their shopping cart, and place orders.

---

# Functional Requirements

## User Registration

The system shall allow new users to create an account.

---

## User Login

The system shall allow registered users to log in using a valid email and password.

---

## Product Search

The system shall allow users to search for products by keyword.

---

## Shopping Cart

The system shall allow users to add and remove products from the shopping cart.

---

## Checkout

The system shall allow logged-in users to complete the checkout process.

---

## Contact Us

The system shall allow users to submit inquiries using the contact form.

---

## Logout

The system shall allow logged-in users to log out successfully.
